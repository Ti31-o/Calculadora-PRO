🧮 Calculadora Python Pro

Uma calculadora interativa desenvolvida em Python, com foco em lógica matemática, tratamento de erros, testes automatizados e visualização detalhada dos cálculos.

O projeto reúne funcionalidades matemáticas, uma interface interativa, ferramentas para validação de resultados e recursos para facilitar o entendimento do código.

🚀 Funcionalidades

🧮 Operações Matemáticas

- Operações matemáticas básicas.
- Cálculo de porcentagem sobre um valor.
- Acréscimo percentual.
- Desconto percentual.
- Operação de resto da divisão ("mod"), separada do cálculo de porcentagem.
- Formatação de resultados para evitar casas decimais desnecessárias.

💻 Terminal Interativo (CLI)

- Menu interativo com opções de 0 a 9.
- Entrada de valores passo a passo.
- Mensagens contextuais para orientar o usuário.
- Execução de exemplos e cenários predefinidos.

🧪 Testes Automatizados

- Suíte de testes unitários com "unittest".
- Validação dos resultados matemáticos.
- Testes com números inteiros e decimais.
- Verificação de casos de borda, incluindo porcentagem de 0% e 100%.
- Tratamento de erros, incluindo divisão por zero e entradas inválidas.

📊 Interface Visual e Detalhamento

- Interface visual interativa.
- Atalhos para executar exemplos de cálculos.
- Exibição passo a passo das fórmulas matemáticas.
- Visualização dos resultados e do histórico da sessão.

📝 Visualizador de Código e Histórico

- Visualização do código com numeração de linhas.
- Opção de download dos arquivos Python.
- Histórico de cálculos realizados.
- Recursos para copiar e exportar resultados.

📂 Estrutura dos Arquivos Python

Os módulos Python previstos para a implementação são:

- "calculadora.py" — lógica matemática e funções de cálculo.
- "test_calculadora.py" — testes automatizados das funcionalidades.

A estrutura final depende dos arquivos efetivamente presentes no repositório.

🎯 Objetivo do Projeto

Este projeto foi desenvolvido para praticar e demonstrar conhecimentos em programação Python, organização de código, implementação de funcionalidades, testes automatizados e construção de interfaces interativas.

A proposta é unir funcionalidade, clareza e confiabilidade, tornando os cálculos mais fáceis de executar e compreender.
